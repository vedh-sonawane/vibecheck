# Vibe Check

Emotional weather system for Slack teams. Detects burnout, tension, and engagement drops before they become problems.

## Built For
Slack Agent Builder Challenge 2026

## Tech Stack
- Slack Bolt Framework
- TypeScript
- Real-Time Search (RTS) API
- MCP Integrations

## Features (In Progress)
- [x] Basic Slack agent setup
- [ ] Message metadata collection
- [ ] Pattern detection engine
- [ ] Team health dashboard
- [ ] Proactive manager alerts

## Setup
```bash
npm install
cp .env.example .env
# Add your Slack tokens to .env
npm run dev
```
